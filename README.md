Alphanume provides proprietary, point-in-time market datasets for quantitative trading, offering a dashboard, REST API, and MCP to access full historical and current observations. Built by a small quantitative trading team, Alphanume handcrafts datasets to deliver actionable, predictive insights beyond price data alone, enabling users to explore and integrate market data into their strategies.

**Areas:** Company · Data · Finance · Quantitative · MarketData

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Alphanume: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
